# Demo Call Script — Metro Property Shop Voice Agent

Call **+1 (659) 234-7944**. Read the caller lines naturally, in your own voice/pace — don't rush,
and let the agent finish speaking before you reply. This script is designed to show off every
major capability in one clean call: listing search, the current offer, bilingual code-switching,
lead capture, and a graceful close.

---

**Agent:** *"Namaste! Welcome to our property shop. How can I help you today?"*

**You:** "Hi, I'm looking to rent a 2 bedroom flat in Dwarka."

**Agent:** *(matches a real listing, asks a follow-up — e.g. budget)*

**You:** "Yes, that sounds good. Do you have any ongoing offers right now?"

**Agent:** *(mentions the zero-brokerage-fee offer)*

**You:** "Accha, ek aur sawal — kya aap Saket mein bhi kuch dikhate hain?"
*(— switch to Hindi here, to show the agent handles both languages in the same call)*

**Agent:** *(replies in Hindi, describes the Saket listing)*

**You:** "Bahut badhiya! Mera naam Rohan hai aur mera number 98XXXXXXXX hai. Kal shaam ko ek visit fix kar dijiye."
*(give any 10-digit number here — it just needs to sound like a real one)*

**Agent:** *(confirms the details, saves the lead)*

**You:** "Dhanyawad, bas itna hi tha."

**Agent:** *(gives a warm closing line with the callback number, ends the call)*

---

### Notes for whoever's calling
- After you finish speaking each line, there will be a short pause with a soft "thinking" sound
  (e.g. "Hmm... just a second...") before the agent replies — that's normal, not a bug.
- Speak clearly and pause briefly when you're done with each line, so the system knows you've
  finished talking.
- The whole call will likely run 2–4 minutes including the thinking pauses, even though the
  actual talking is under 90 seconds.
